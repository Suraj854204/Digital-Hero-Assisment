# Changelog

## Version 1.0.0

### Improvements Made

- Built the website using Next.js 15, TypeScript, and Tailwind CSS.
- Made the layout fully responsive for mobile, tablet, and desktop.
- Added smooth animations using Framer Motion.
- Implemented client-side form validation using React Hook Form and Zod.
- Improved accessibility by using semantic HTML, proper headings, focus states, and form labels.
- Optimized fonts using `next/font` for better loading performance.
- Added metadata, robots.txt, and a web manifest for better SEO.
- Added the required footer attribution for the Digital Heroes training task.

### Expected Result

- Better page loading performance.
- Improved accessibility.
- Responsive user experience across devices.
- Better Lighthouse Performance and Accessibility scores.
